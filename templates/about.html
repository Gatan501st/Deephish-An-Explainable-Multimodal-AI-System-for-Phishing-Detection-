About DeepPhish

DeepPhish is an explainable multimodal AI system designed to detect and analyze phishing emails with high accuracy. Our platform combines state-of-the-art natural language understanding, threat intelligence, and comprehensive security analysis to protect users from email-based attacks.

Built with transparency and user education in mind, DeepPhish not only identifies potential threats but also explains why content is flagged, helping users understand and recognize phishing attempts in the future.

Key Features

AI-Powered Classification

Uses advanced transformer models fine-tuned on phishing datasets to accurately classify emails as legitimate or phishing.

Email Parsing

Comprehensive EML file parsing with header analysis, body extraction, and attachment handling.

URL & IP Analysis

Integration with VirusTotal API to check URLs and IP addresses against threat intelligence databases.

Attachment Scanning

Hash-based attachment scanning to detect known malicious files and suspicious content.

Risk Assessment

Multi-factor risk scoring that combines various indicators to provide comprehensive threat evaluation.

Explainable AI

Provides clear explanations for why content is flagged, including language cues and feature importance.

Privacy-Focused

Local processing with optional storage. Your data stays under your control.

Educational Content

Comprehensive educational resources to help users understand and protect against phishing attacks.

How It Works

1. Email Input

Users can upload EML files, paste email content, or provide SMS/text messages for analysis.

2. Multi-Modal Analysis

DeepPhish performs several parallel analyses:

  • NLU Engine: Analyzes text content using AI models to detect phishing language patterns
  • Email Processing: Parses email headers, body, and metadata for suspicious indicators
  • External Tools: Checks URLs and IPs against VirusTotal threat intelligence
  • Attachment Analysis: Scans file attachments for known malware signatures

3. Risk Scoring

The system combines all analysis results to generate a comprehensive risk score:

  • LOW: Content appears safe, no immediate threats detected
  • MEDIUM: Some suspicious indicators present, use caution
  • HIGH: Strong indicators of phishing, do not interact

4. Explainable Results

Results include detailed explanations of why content was flagged, including:

  • Classification confidence scores
  • Detected language cues and suspicious phrases
  • URL and IP threat intelligence results
  • Actionable recommendations

Important Disclaimer

DeepPhish is a tool to assist in identifying potential phishing attempts, but it is not infallible.

  • No automated system can detect all phishing attempts with 100% accuracy
  • Always verify suspicious emails through independent channels
  • Use your judgment and follow security best practices
  • Do not rely solely on automated tools for security decisions
  • When in doubt, delete suspicious emails or contact the organization directly

DeepPhish should be used as part of a comprehensive security strategy, not as the sole method of protection.

Privacy & Security

We take privacy seriously:

  • Email content is processed locally on your machine or server
  • Optional JSON storage for analysis results (user-controlled)
  • No data is sent to third parties except for threat intelligence lookups (VirusTotal)
  • All API keys and sensitive credentials should be stored securely
  • Source code is available for review and auditing

Usage Guidelines

To get the best results from DeepPhish:

  1. Upload complete emails: Include headers when possible for better analysis
  2. Check URLs separately: Use the URL/IP analysis feature for suspicious links
  3. Review explanations: Pay attention to why content is flagged
  4. Combine with education: Learn from flagged patterns to improve your own detection skills
  5. Report false positives: Help improve the system by understanding edge cases
